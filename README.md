Hi Fⁱ! If you clone this repo to your local machine, you can run the below commands to get started :frog:

```bash
python3 -m venv .venv
```

```bash
source ./.venv/bin/activate
```

```bash
python3 -m pip install --upgrade pip
```

```bash
python3 -m pip install streamlit pandas
```

Run the app locally on port 8501:
```bash
python3 -m streamlit run app.py
```
